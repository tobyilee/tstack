## 모델

이 슬라이스에는 실행하는 도메인 모델이 없다. 아래의 넷이 서로 맞아야 하는 것이 모델이다.

| 것 | 가진 것 | 가리키는 것 |
|---|---|---|
| 마켓플레이스 매니페스트 | 마켓플레이스의 이름, 플러그인의 항목 2개 | 항목의 `source`가 플러그인의 폴더를 가리킨다. |
| 플러그인의 폴더 | 플러그인 매니페스트, 부품, `README.md`, `LICENSE` | 폴더의 밖을 가리키지 않는다 (AC-2.1). |
| 릴리스의 태그 | 플러그인의 이름, 버전 | 태그가 가리키는 커밋의 플러그인 매니페스트. |
| 출처의 기록 | 출처 저장소, 출처 커밋, 파일의 항목 78개 | 항목이 옮긴 파일을 가리킨다. |

도메인 모델이 아닌 것: 스킬의 글의 내용, 검사의 코드, CI의 설정.

## 규칙

| ID | 수준 | 규칙 | 지키는 곳 |
|---|---|---|---|
| R1 | MUST | 플러그인의 이름은 세 곳에서 **반드시** 같아**야 한다**: 플러그인의 폴더의 이름, 플러그인 매니페스트의 `name`, 플러그인의 항목의 `name`. | 마켓플레이스 매니페스트, 플러그인 매니페스트 |
| R2 | MUST | 플러그인의 항목의 `source`는 **반드시** `./plugins/<플러그인의 이름>`이어**야 한다**. | 마켓플레이스 매니페스트 |
| R3 | MUST | 버전은 **반드시** 점으로 나눈 숫자 3개여**야 한다** (`<숫자>.<숫자>.<숫자>`). | 플러그인 매니페스트 |
| R4 | MUST NOT | 플러그인의 항목은 `version`을 **절대** 가져**서는 안 된다**. | 마켓플레이스 매니페스트 |
| R5 | MUST | 릴리스의 태그가 가리키는 커밋에서, 플러그인 매니페스트의 버전은 **반드시** 태그의 버전과 같아**야 한다**. | 릴리스의 태그 |
| R6 | MUST | `LICENSE` 3개(저장소의 뿌리 1개, 플러그인의 폴더 2개)의 내용은 **반드시** 같아**야 한다**. | 저장소의 뿌리, 플러그인의 폴더 |
| R7 | MUST | eval 사례의 폴더는 **반드시** `prompt.md`를 가져**야 한다**. | eval 사례 |
| R8 | MUST | eval 사례의 폴더는 **반드시** `graders/`의 안에 `.md` 파일을 1개 이상 가져**야 한다**. | eval 사례 |

규칙의 이유:

- R1: 이름이 다르면 `claude plugin install <이름>@tstack`이 다른 것을 찾는다.
- R4: 버전이 두 곳에 있으면 서로 다른 값이 된다. 플러그인 매니페스트가 먼저다 (읽음 (agent): 브레인스토밍의 D4).
- R5: 태그의 이름과 내용이 다르면 "어느 판을 쓰는가"의 답이 틀린다.
- R6: 설치는 플러그인의 폴더만 복사한다. 뿌리의 `LICENSE`는 설치한 사본에 없다.
- R7, R8: `claude plugin eval`이 요구하는 모양이다 (읽음 (agent): 브레인스토밍의 D8).
